⚡ Conexão Automática — Google Apps Script
O servidor do Tesouro Transparente bloqueia requisições diretas do navegador (CORS). A solução é criar um proxy gratuito no Google Apps Script — leva menos de 3 minutos e funciona para sempre, sem custo.
1
Acesse script.google.com, clique em Novo projeto e apague o conteúdo padrão.
2
Cole o código abaixo e clique em Salvar:
function doGet(e) { var url = 'https://www.tesourotransparente.gov.br/ckan/dataset/' + 'df56aa42-484a-4a59-8184-7676580c81e3/resource/' + '796d2059-14e9-44e3-80c9-2d9e30b405c1/download/precotaxatesourodireto.csv'; var response = UrlFetchApp.fetch(url, { muteHttpExceptions: true, followRedirects: true }); var content = response.getContentText('windows-1252'); return ContentService .createTextOutput(content) .setMimeType(ContentService.MimeType.TEXT); }
3
Clique em Implantar → Nova implantação.
Tipo: App da Web · Executar como: Eu · Acesso: Qualquer pessoa.
Clique em Implantar e copie a URL gerada.
4
Cole a URL aqui e clique em Salvar e Conectar:
